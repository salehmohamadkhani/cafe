راه‌اندازی خیلی سریع سامانه مدیریت کافه در ویندوز
=================================================

1) کل پروژه را از GitHub به‌صورت ZIP دانلود کنید.
2) فایل ZIP را کامل Extract کنید؛ برنامه را داخل ZIP اجرا نکنید.
3) داخل پوشه استخراج‌شده روی INSTALL_AND_RUN.bat دوبار کلیک کنید.
4) بار اول مسیر پوشه پروژه پرسیده می‌شود. اگر BAT داخل همان پوشه است فقط Enter بزنید.
5) نصب‌کننده Python، محیط مجازی، کتابخانه‌ها و دیتابیس را بررسی می‌کند.
6) بعد از آماده‌شدن، مرورگر خودکار روی http://127.0.0.1:5000 باز می‌شود.
7) پنجره CMD را باز نگه دارید. برای توقف سرور داخل همان پنجره Ctrl+C بزنید.

ورود مدیریت مرکزی محلی:
نام کاربری: admin
رمز عبور: admin

بعد از ورود، ابتدا یک کافه بسازید و ماژول‌ها و ساختار انبار آن را انتخاب کنید.
راهنمای کامل در README.md قرار دارد.
